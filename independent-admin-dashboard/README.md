# مدار — لوحة إدارة مستقلة

لوحة إدارة عربية RTL مستقلة تمامًا عن Django. لا تقرأ ملفات مشروع Django، ولا تتصل بقاعدة بياناته، ولا تحتاج إلى أي حزمة أو عملية بناء.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. تحفظ العمليات التجريبية في `localStorage` داخل المتصفح، ويمكن استعادة بيانات البداية من: الإعدادات ← استعادة البيانات التجريبية.

لخدمة الملفات محليًا، يمكن استخدام أي خادم ملفات مستقل. إذا توفر Python:

```powershell
cd independent-admin-dashboard
python -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## حدود التكامل

هذه اللوحة مستقلة حسب الطلب، لذلك لا تدّعي تعديل بيانات المنصة الفعلية حاليًا. الربط الإنتاجي الصحيح يكون عبر خدمة API مستقلة بعقد مصادقة وصلاحيات واضح، دون استيراد Django أو الوصول المباشر إلى `db.sqlite3`. الوحدات المغطاة في تجربة الواجهة:

- لوحة المؤشرات والتحليلات.
- المنتجات، التصنيفات، المتغيرات، والمخزون.
- الطلبات والشحن والمدفوعات والاستردادات.
- العملاء وبيانات الاتصال المقنّعة.
- الإعلانات، الصفحات، الرسائل، التقييمات، والكوبونات.
- التسويق، الفريق، الأدوار والصلاحيات.
- إعدادات المتجر والتنبيهات وسجل النشاط.

## الأمان المقترح للإنتاج

- مصادقة متعددة العوامل وجلسات قصيرة المدة.
- RBAC بصلاحيات دقيقة لكل عملية.
- CSRF للعمليات المعتمدة على cookies أو استخدام Bearer tokens آمنة.
- سجل تدقيق غير قابل للتعديل، وإخفاء البيانات الحساسة.
- تأكيد إضافي للحذف والاسترداد والإجراءات المالية.
